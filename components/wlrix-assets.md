# Assets

<code>wlrix-assets</code> &middot; data &middot; shared icons, cursors, wallpapers and palette

Shared branding and look-and-feel data, consumed by **both** the Rust system components and the C# apps so everything renders identically. Licensed MIT, unlike the rest of the project, so it is freely reusable.

`palette/` holds the canonical color palette — the single source of truth for theming, and the origin of every color on this website. `themes/` holds the wlRIX GTK stylesheets and their titlebar assets, `icons/` the icon theme, and `wallpapers/` the desktop backgrounds, including the scatter tiled behind this page.
